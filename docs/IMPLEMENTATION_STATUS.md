## Открытые вопросы владельцу (пока не блокируют работу)
1. **GitHub push-доступ**: у сессии нет PAT/`gh auth` для пуша в `Mefisto767/genesis-garden`. Работа продолжается локальными коммитами в песочнице; когда будет готов очередной стабильный этап, потребуется либо PAT (repo scope) от владельца, либо сам владелец должен будет запушить подготовленную ветку/патч.
2. **Supabase проект**: понадобится URL + anon key (публичные, можно передать в чат) для реальной интеграции; до этого момента вся работа Этапа 3 идёт как воспроизводимые миграции + локальный Supabase CLI (если будет установлен) — интеграция в живой проект произойдёт, когда ключи появятся.
3. **Paddle sandbox аккаунт**: нужен для реального sandbox-чекаута; до получения — adapter пишется полностью, но не подключается к живому Paddle, работает mock provider.
