# Genesis Garden — Art Vertical Slice A (integration lock)

Статус: **принято**, три ассета — первый production-art proof, описанный в
`docs/VISUAL_PRODUCTION_ROADMAP.md` §«Первый art proof после V1» (plot base
64×64, Солнечник mature 64×96, neutral unrevealed plant 64×96). Это
docs-only коммит-замок: фиксирует точные хэши/размеры/scope ДО того, как в
следующем коммите появятся сами файлы и код интеграции — если что-то из
зафиксированного здесь разойдётся с реально закоммиченным, это баг ревью, а
не молчаливое разночтение.

## Источник

Пакет `art_v2` (zip), доставлен владельцем, хэши сверены владельцем против
`SHA256SUMS` пакета до начала интеграции.

## Куда подключаются (сужение по коду, зафиксировано ДО написания кода интеграции)

- **`plot_empty`** — заменяет `tile_soil` как базовый тайл грядки
  (`EstateScene.addTile()`) для ЛЮБОЙ незаблокированной грядки — пустой,
  растущей, готовой, постоянного V2-гибрида — той же ролью, что `tile_soil`
  уже играет сегодня (единая база под растением, а не только для
  буквально-пустой клетки). `tile_soil_locked` не входит в объём пакета и не
  меняется.
- **`plant_hybrid_unrevealed`** — заменяет процедурный `buildPlantSprite()`
  ТОЛЬКО в `renderHybridPlotCell()`, ветка `hybridV2.phase === 'growing'`
  (Genetics V2 lifecycle — посажен/растёт/готов-но-не-собран; сбор вызывает
  Reveal, после которого рендер переключается на ветку `mature` ниже —
  ровно это и есть «planted/growing/pending-Reveal» из ТЗ пакета). Legacy
  (non-V2) посадка и `renderHybridPlotCellReadOnly` (Overhaul + Legacy
  Genetics) НЕ затрагиваются — они и так не показывают фенотип.
- **`plant_sunflower_mature`** — заменяет процедурный рендер ТОЛЬКО в ветке
  `phase === 'mature'`, и только когда `specimen.genome.shape === 1`
  (speciesId 1 = Солнечник, `claude/GENETICS_GATE1_IMPLEMENTATION_CONTRACT.md`
  §4.6.2) **и** `specimen.genome.primary === '#FF8C77'` (`primary_coral`,
  `PRIMARY_HEX_TO_ID` в `geneticsV2.ts`) — то есть только для того самого
  фенотипа, который художник реально нарисовал (коралловый Солнечник).
  Любой другой вид/основной цвет продолжает получать существующий
  послойный процедурный рендер без изменений. **Осознанное сужение**: этот
  единственный плоский PNG физически не может честно представить все 8
  вариантов `secondaryColor`/`leafColor` того же коралового Солнечника —
  он один и тот же вне зависимости от вторичного/листового цвета
  конкретного specimen. Для узкого vertical slice это принято как известное
  ограничение (не баг), а не молчаливая замена процедурной системы.

## Явно не входит в объём (без изменений в этом проходе)

Лаборатория, персонаж, Люми, terrain/paths, полный каталог видов (только
Солнечник — Колокольник не тронут), анимация, редизайн UI, генетика/RNG/
экономика/Reveal-семантика/feature flags, `tile_soil_locked`.
