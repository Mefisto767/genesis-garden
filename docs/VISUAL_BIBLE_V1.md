# Genesis Garden — Visual Bible V1

Статус: production lock первого визуального прохода после Genetics Gate 1.  
Область: поместье, стартовый сад, растения, HUD и лаборатория.  
Эталон логики: committed HEAD `d59177a` и Genetics Gate 1 contract.

## 1. Цель

Игра должна выглядеть как тёплое, ручное ботаническое приключение, а не как
обычная ферма и не как перегруженный AI-концепт. Внешний сад даёт ясность,
уют и желание обустраивать территорию. Лаборатория даёт контраст, тайну и
ощущение открытия.

Рабочее название стиля: **Botanical Fantasy Pixelcraft**.

Обязательные качества:

1. С первого взгляда понятно, куда можно идти, что является грядкой и какое
   растение относится к какой грядке.
2. Каждый гибрид визуально отличается через системные слои, а не через
   отдельную случайно сгенерированную картинку.
3. Мир выглядит богатым за счёт композиции, света и анимации, а не за счёт
   бесконтрольного количества мелких деталей.

## 2. Что принято из референсов

Принято:

- верхняя камера с мягкой перспективой 3/4;
- тёплый дневной стартовый сад с тёмно-зелёной рамкой зарослей;
- каменно-земляные дорожки, дерево, состаренная латунь и стекло;
- крупные, хорошо отделённые грядки;
- лаборатория как самостоятельная полноэкранная сцена;
- более глубокий контраст и свечение в лаборатории;
- крупный рабочий стол и понятные интерактивные точки.

Не принято:

- готовый AI-скриншот как фон игровой карты;
- фотореалистичный свет и сотни мелких бликов;
- разный масштаб зданий, персонажа и растений между экранами;
- орнамент на каждой свободной поверхности;
- одинаково яркие объекты без визуальной иерархии;
- тусклая серо-зелёная картинка;
- тесные ряды растений, где непонятна принадлежность к грядке.

## 3. Техническая система координат

Уточнение контракта (V1 foundation): прежняя формулировка «960×540 +
только целочисленный масштаб на любых экранах» невыполнима — на
произвольном мобильном viewport строгий целочисленный CSS-scale
невозможен. Действующий контракт ниже.

| Параметр | Production lock |
|---|---:|
| Контрольный desktop viewport | 960×540 px (reference, НЕ фиксированный размер canvas) |
| Canvas | responsive: заполняет реальный viewport (Phaser `Scale.RESIZE`) |
| Рендер | `pixelArt: true`, `roundPixels: true`, nearest-neighbour |
| Базовый тайл мира | 32×32 px |
| Полный мир | 48×48 тайлов, 1536×1536 px |
| Стартовая зона | 18×16 тайлов, 576×512 px |
| World coordinates / anchors | целочисленные (px в мировой системе) |
| Камера | cover-подход по `CAMERA_BOUNDS`, следует за персонажем |
| Camera zoom | дробный разрешён; безопасный диапазон, см. ниже |
| Персонаж | visual box 32×48 px |
| Люми | visual box 32×40 px |
| Зрелое растение | до 64×96 px, anchor bottom-center |
| Стартовая грядка | footprint 64×64 px |
| Шаг центров грядок | 96 px по X и Y |
| Минимальный просвет | 32 px между footprints |
| Touch target | минимум 44×44 CSS px |

960×540 — контрольный desktop viewport для визуального приёма и
скриншот-ревью, а не фиксированный размер canvas. Phaser Overhaul сохраняет
responsive canvas: он всегда заполняет реальный viewport целиком.

Камера использует cover-подход относительно `CAMERA_BOUNDS`
(worldConfig.ts): zoom выбирается так, чтобы видимая область мира никогда
не выходила за границы `CAMERA_BOUNDS` — на landscape камера покрывает
ширину `CAMERA_BOUNDS`, на portrait — высоту. Формула:
`zoom = max(viewportWidth / boundsWidth, viewportHeight / boundsHeight)`,
ограниченный безопасным диапазоном [`MIN_CAMERA_ZOOM`, `MAX_CAMERA_ZOOM`];
при конфликте требование «не показывать пустое пространство за
`CAMERA_BOUNDS`» сильнее верхней границы диапазона. Камера следует за
персонажем; весь мир 48×48 одновременно не показывается никогда.

Fractional camera zoom разрешён, если иначе невозможно корректно заполнить
произвольный viewport (это масштаб КАМЕРЫ, единый для всего мира —
геометрия между объектами не искажается). По-прежнему не допускаются:
линейная фильтрация, дробные world-координаты/anchors и переменный размер
одного и того же объекта от сцены к сцене. Classic renderer
(`PhaserGame.ts` + `GardenScene`) этим контрактом не затрагивается и не
меняется.

## 4. Визуальная иерархия

Игрок считывает сцену в таком порядке:

1. персонаж и ближайшее доступное действие;
2. готовые к сбору растения;
3. отдельные грядки и дорожки;
4. двери активных зданий;
5. ресурсы и текущая цель в HUD;
6. декор и фоновые анимации.

Декор не может быть контрастнее готового растения, активной двери или
интерактивного указателя. На одном экране одновременно пульсирует не более
трёх объектов.

## 5. Палитра и материал

| Роль | Правило |
|---|---|
| Контур | тёплый тёмно-коричневый, не чистый чёрный |
| Трава | насыщенный средний зелёный, тёмная кромка |
| Дорожка | песочно-охристая, на 15–25% светлее травы |
| Почва | тёплая тёмно-коричневая, явно отличается от дорожки |
| Дерево | ореховое, 3–4 тона |
| Камень | тёплый серо-бежевый, без синей стерильности |
| Латунь | приглушённое золото, яркий пиксель только на блике |
| Стекло | бирюзово-голубое, прозрачность задаётся спрайтом/alpha |
| Магия | бирюза, фиолетовый или янтарный; один главный акцент на объект |

Обычный world-спрайт использует ориентировочно 12–24 цвета. Полупрозрачные
пиксели на контурах запрещены. Исключения — отдельные glow/effect-слои.

## 6. Стартовый сад

Стартовый сад не является законченным поместьем. Он даёт уютную рабочую
площадку и одновременно показывает четыре направления расширения.

Опорные точки:

- дом — домашний якорь;
- лаборатория/оранжерея — главный aspirational-объект;
- шесть грядок — ежедневный рабочий блок;
- склад — второстепенная функция;
- Люми и её станция — навигация/обучение;
- малый пруд — спокойная природная точка;
- центральная поляна — свободное место, а не памятник;
- четыре закрытых прохода.

### 6.1. Грядки

Шесть стартовых грядок располагаются сеткой 3×2. Каждая грядка:

- имеет собственную каменную или деревянную кромку;
- содержит ровно одну посадочную точку по центру;
- имеет footprint 64×64 px и hit area не меньше 72×72 px;
- отделена от соседней минимум одним полным тайлом;
- не перекрывается растением соседней грядки в обычном состоянии;
- получает внешний selection-outline, не меняющий размер спрайта.

Целевая сетка относительно первого центра:

| Plot | Смещение X | Смещение Y |
|---:|---:|---:|
| 0 | 0 | 0 |
| 1 | 96 | 0 |
| 2 | 192 | 0 |
| 3 | 0 | 96 |
| 4 | 96 | 96 |
| 5 | 192 | 96 |

Будущие 18 грядок открываются в `zone_working_farm` тремя блоками по 3×2.
Так максимум остаётся 24, но стартовая зона не превращается в тесную таблицу.

### 6.2. Дорожки и проходы

- Основной путь имеет ширину 2 тайла около центральной поляны и 1–2 тайла
  в ответвлениях.
- Дверь каждого активного здания соединена с основным путём.
- Путь не проходит через hit area грядки.
- Закрытый проход показывает часть будущего биома за воротами, но не полный
  объект-награду.
- В каждом направлении остаётся corridor минимум 2 тайла.

## 7. Состояния грядки и растения

Физический вид несёт основную информацию. Текст появляется контекстно.

| Состояние | Вид в мире | Действие |
|---|---|---|
| Locked | заросшая почва + небольшой замок | показать цену |
| Empty | чистая почва + ненавязчивый знак посадки | открыть выбор семени |
| Seed | холмик, бирка, 1–2 пикселя влаги | показать таймер |
| Sprout | маленький росток | показать таймер |
| Young | узнаваемый стебель/листья | показать таймер |
| Bud | бутон, финальный phenotype скрыт | показать таймер |
| First ready | bloom + ready-маркер | собрать и открыть Reveal |
| Mature | постоянное зрелое растение | открыть карточку |
| Regrowing | зрелая основа + незрелый плод/пыльца | показать таймер |
| Repeat ready | зрелая основа + новый плод/пыльца | повторный сбор |

Визуальная дискретизация роста:

- Seed: 0–8%;
- Sprout: 8–45%;
- Young: 45–85%;
- Bud: 85–100%;
- Ready: только `ready === true` из стора.

Единственный источник времени — существующие `progress`, `remainingMs` и
`ready` из `GameStore`.

### 7.1. Таймер

Постоянные полосы на всех грядках запрещены: они превращают сад в dashboard.

- на расстоянии видна физическая стадия;
- desktop hover или близость персонажа: плашка `Рост · 03:42`;
- tap по растущей грядке: плашка закрепляется на 3 секунды;
- selected detail: точное время и прогресс;
- ready: таймер исчезает, появляются shape-marker, pulse и действие;
- HUD: агрегат `Готово: N`, только если `N > 0`.

Готовность нельзя кодировать только цветом. Минимум два сигнала: форма/иконка
и анимация; цвет является третьим вспомогательным сигналом.

## 8. Генетическое растение

Гибрид собирается из слоёв одинакового canvas и anchor:

1. `shadow`;
2. `stem/silhouette`;
3. `leaf_shape`;
4. `leaf_color`;
5. `flower_shape`;
6. `primary_color`;
7. `secondary_color`;
8. `pattern`;
9. `size_transform`;
10. `aura/mutation_fx`.

Слои совпадают пиксель-в-пиксель на canvas 64×96 px. Color-mask PNG белые
с alpha 0/255; цвет назначается tint'ом в Phaser.

До первого созревания и подтверждения Reveal гибрид отображается нейтральной
версией стадии. Реальные цвет, узор, мутация, редкость и генетика не должны
угадываться по world-спрайту. При maturity:

1. нейтральное растение получает закрытый ready-marker;
2. сбор открывает Reveal;
3. после подтверждения neutral layers заменяются реальными;
4. растение остаётся на грядке;
5. повторно растёт только плод/пыльца, не само растение.

## 9. Редкость без визуального шума

| Tier | World treatment |
|---|---|
| Common | без постоянного эффекта |
| Uncommon | один редкий спокойный sparkle |
| Rare | слабый rim/accent |
| Epic | редкий цветовой pulse aura |
| Legendary | уникальный медленный particle motif |
| Mythic | aura + уникальный idle beat; не постоянный фейерверк |

Rarity frame живёт в карточке. В мире редкость подчёркивает phenotype, но не
заменяет его и не раскрывает до Reveal.

## 10. Лаборатория

Лаборатория — отдельный authored background 960×540 px с интерактивными
слоями, а не второй тайловый мир. Пять зон читаются без подписей:

- workbench;
- showcase;
- botanical book;
- microscope;
- dryer/recycling cabinet.

Сцена делится на base background, foreground occluders, hotspot idle/hover
overlays, ambient animations и React UI. Дневной L1 задаёт ясность. Тёмная
ночная версия — поздний уровень/режим, а не случайная смена стиля.

## 11. UI

Phaser отвечает за мир. React/CSS отвечает за HUD, панели, карточки, выборы,
таймеры и доступность.

- touch target минимум 44×44 CSS px;
- основной текст минимум 14 CSS px, критический — 16 px;
- world UI не закрывает персонажа и грядки без действия игрока;
- desktop: компактные панели у краёв;
- mobile: bottom sheet до 70–80vh;
- один главный CTA на панели;
- raw genetic ID никогда не показывается.

HUD V1: монеты, пыльца, пыль, готовые растения, текущая цель и одна кнопка
меню. Нынешняя строка текстовых кнопок заменяется после утверждения skin-пака.

## 12. Критерий визуального приёма

На 50% масштаба без пояснений пользователь должен:

1. указать все шесть отдельных грядок;
2. сопоставить каждое растение ровно одной грядке;
3. найти персонажа за одну секунду;
4. найти лабораторию и её дверь за две секунды;
5. отличить ready от growing без чтения текста;
6. увидеть хотя бы два будущих направления развития;
7. не принять декор за интерактивный объект.

Если один пункт не выполняется, кадр не идёт в массовую генерацию и билд.
