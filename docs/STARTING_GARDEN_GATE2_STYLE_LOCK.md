# Genesis Garden — Starting Garden Gate 2 Style Lock

Статус: runtime art-test. Механика и layout уже зафиксированы отдельно в
`CROSSROADS_ESTATE_CANONICAL_BLUEPRINT.md`; этот документ не меняет их.

## Зачем этот gate

Предыдущие проходы смешивали три разные задачи: layout, механику и рисование.
Из-за этого локально «улучшенная» текстура могла ухудшить весь экран. Gate 2
разделяет ответственность:

1. `estateBlueprint.ts` и `estateProgression.ts` определяют мир и расширения;
2. `worldConfig.ts` определяет координаты, footprints и взаимодействия;
3. `assetManifest.ts` подставляет визуальный файл по стабильному ID;
4. арт не имеет права менять пункты 1–2;
5. production approval выдаётся только после скриншотов реального билда.

## Единый style target

`docs/reference/starting_garden_style_target_v1.png` — эталон материалов,
палитры, света и относительной визуальной иерархии. Это не background-карта и
не источник координат.

Обязательные признаки:

- Botanical Fantasy Pixelcraft, тёплый свет сверху-слева;
- спокойная природная трава и мягкие земляные дорожки;
- тёмный коричневый контур без чёрной «обводки наклейки»;
- дом и лаборатория — главные массы;
- склад и станция Люми — вторичные массы;
- грядки и растения остаются главной интерактивной зоной;
- никакого checkerboard, цепочек кругов, лепесткового пруда и повторяющегося
  «глаза» изгороди.

Исходники лежат в `apps/web/art_source/v1/gate2/`. Runtime candidates — в
`apps/web/public/assets/v1/buildings/`. Статус в runtime-манифесте остаётся
`temporary`, пока desktop/mobile скриншоты не приняты владельцем. Это
предотвращает ложное объявление AI-исходника финальным production-артом.

## Неприкосновенный контракт

- шесть стартовых грядок и их pitch не меняются;
- четыре прохода соответствуют северу/востоку/западу/югу Crossroads Estate;
- первое расширение: север, +6 outdoor и +4 greenhouse;
- восток: три aquatic habitat, не обычные грядки;
- коллизии, world coordinates, камера, GameStore, RNG, генетика, экономика и
  save schema не меняются;
- полный style target никогда не загружается в игру как единая картинка.

## Критерий следующего решения

Art-test принимается или отклоняется целиком по реальным кадрам 1440×900,
960×540 и 360×800. После принятия производится семейство Architecture Slice C
в том же масштабе; до принятия новые здания и декор не генерируются.
