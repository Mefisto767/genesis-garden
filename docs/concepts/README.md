# Концепт-арт — статус

## Артборд (4 сцены), упомянутый в постановке задачи

Задание ссылается на приложенный концепт-артборд («целевой уровень и единое
настроение внешнего мира, лаборатории, раскрытия гибрида и визита к другу»)
как на визуальный ориентир этого этапа. **Файл изображения фактически не
был приложен к сессии** — вместе с ТЗ пришли только два текстовых файла
(`genesis-garden-final-vision-gdd.md` и техпромт на Visual Overhaul).
`docs/concepts/genesis-garden-vision-board.png`, который просила сохранить
постановка задачи, поэтому отсутствует.

Не блокирую реализацию из-за этого: GDD (`docs/FINAL_VISION.md`, разделы 12
«Визуальное направление» и 20) достаточно подробно описывает целевой стиль
(Botanical Fantasy Pixelcraft, top-down 32×32, тёплая палитра, лаборатория —
детализированный иллюстрированный фон), а в привязанном проекте claude.ai уже
есть история предыдущих визуальных решений (`style-directions.md`,
`fable-art-brief.md`) — тот же дух Bold cartoon-farm → 16-bit pixel-art,
которому уже следует существующий арт-пак (`apps/web/public/assets/`).
Вертикальный срез реализован на этой текстовой основе плюс существующем
пиксельном арт-паке v0.3.
